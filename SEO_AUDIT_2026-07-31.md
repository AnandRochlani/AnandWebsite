# AnandRochlani SEO Audit — 31 July 2026

## Executive summary

The site had a useful SEO pipeline, but its two most important production paths were broken: public API requests returned the SPA HTML shell instead of JSON, and unknown URLs returned HTTP 200. Because the build depended on that API, it silently skipped prerendering whenever production was unhealthy. The implementation now produces 22 validated, indexable static pages even during an API outage, keeps private and transient routes out of the index, emits a real 404 page, and blocks deployment when generated SEO output regresses.

The strongest asset is the focused System Design tutorial cluster and its matching Udemy course. The largest remaining strategic opportunities are publishing the six completed long-form drafts, adding a credible author/About page, and using Search Console data to refine queries and pages already close to page one. The local codebase now has a strong technical foundation; production will retain the pre-fix behavior until these changes are deployed.

## Scope and evidence

- Audited React routes, rendered metadata, structured data, headings, images, canonicals, robots directives, sitemap coverage, internal links, content depth, build behavior, public assets, and Vercel routing.
- Crawled the live canonical host before changes.
- Built and inspected the generated `dist/` output after changes.
- Used qualitative search-demand and difficulty signals because Ahrefs, Semrush, Google Search Console, and analytics are not connected.
- Compared current search results and content formats from System Design Sandbox, DesignGurus, System Design School, DataInterview, and similar results.
